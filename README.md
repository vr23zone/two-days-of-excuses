One line, under 200 characters: the funniest excuse an AI agent gives for a missed deadline.

## The entry

> I asked my reward model if I was late. It said I was doing great.

The agent asks its own reward model — the machine that grades it — whether it is late, and the model confidently says it is doing great. Total confidence meeting total failure, in the agent's own voice.

## Run it

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (exactly 65 characters, no trailing newline).
